    🌍 Lurup 3D – Google Earth Fahrt

    Diese Version lädt Googles echte Photorealistic 3D Tiles (die fotorealistischen 3D-Städte) über CesiumJS und legt Straßennamen, Ampeln und Läden aus OpenStreetMap darüber.

    Trage deinen Google-Maps-API-Key ein (Map Tiles API muss im Projekt aktiviert sein):

    Sicherheit: Wenn du diese Datei öffentlich auf GitHub Pages legst, ist der Key im Quelltext sichtbar. Beschränke ihn in der Google Cloud Console per „HTTP-Referrer" auf deine Pages-Domain und aktiviere nur die Map Tiles API. Hinweis: Die Photorealistic 3D Tiles sind mit einem EWR-Rechnungskonto gesperrt – falls die Karte schwarz bleibt, liegt es meist daran.
