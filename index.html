    🌍 Lurup 3D – Google Earth Einkaufsfahrt

    Fährt über Googles fotorealistische 3D-Karte (Photorealistic 3D Maps) – die Kamera bleibt auf Straßenhöhe hinter dem Auto. Mit 🎥 kannst du die Karte frei per Wischen/Zoomen erkunden (Flug über Lurup). Läden und Ampeln kommen aus OpenStreetMap.

    Nötig: Maps JavaScript API + Map Tiles API im Google-Projekt aktiviert. Bei öffentlichem Hosting den Key per HTTP-Referrer auf deine Domain beschränken. Läden/Ampeln © OpenStreetMap (ODbL).
